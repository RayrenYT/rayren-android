# Rayren 0.1.8-alpha

Тестовая версия для Android 8.0+ (ARM64).

- Xray, OpenFlux/Cups и экспериментальный olcRTC в одном VPN-клиенте.
- Удаление и обновление подписок, импорт до 5000 профилей, поиск и страницы по 50 серверов.
- Выбор подписок для режимов «Авто» и «По пингу», резервные БС-маршруты и объяснение выбора сервера.
- Тестовый импорт личной подписки через @rayrenhelpbot, включая Cups при наличии доступа.

Вложения: APK, соответствующие исходники со встроенными зависимостями и SHA256SUMS.txt.
Для обновления установите APK поверх прежней alpha-версии.

Проверки сборки: 157 JVM и 25 Python тестов, native-проверки, подпись APK v2, выравнивание 16 КиБ. Подробности: docs/BUILD_REPORT_0.1.8.md.
Проверка этой сборки на физическом телефоне, расхода батареи и LiveBridge остаётся открытой.
