# Rayren Android

[Скачать APK 0.1.8-alpha](https://github.com/RayrenYT/rayren-android/releases/tag/v0.1.8-alpha) · Android 8.0+ · ARM64 · GPLv3

Тестовый Android-клиент с одним VPN-интерфейсом и встроенными Xray, OpenFlux и olcRTC. В 0.1.8: удаление подписок, импорт до 5000 профилей, отдельный выбор источников AUTO/SMART и типа БС, состояния серверов и объяснение выбора. RU-2 разрешён. Тестовый автоимпорт через @rayrenhelpbot включён: «Серверы → Моя подписка из Telegram» или /rayren в личном чате. Основная подписка и доступный Cups обновляются одной группой «Мой Rayren». Подробности — [отчёт 0.1.8](docs/BUILD_REPORT_0.1.8.md) и [этапы Smart 2](docs/SMART_2_ROADMAP.md).

## Установка и первая проверка

1. Скачайте `Rayren-0.1.8-alpha-arm64-v8a.apk` из [релиза](https://github.com/RayrenYT/rayren-android/releases/tag/v0.1.8-alpha) на телефон и откройте файл. Нужен Android 8.0 или новее с 64-битным ARM-процессором. Устанавливайте поверх предыдущей версии, не удаляя приложение: подпись прежняя, сохранённые профили остаются.
2. Разрешите установку для приложения, которым открыли файл. Запустите Rayren.
3. Нажмите «Добавить подписку». Вставьте одну HTTP/HTTPS-ссылку подписки, URI сервера или отсканируйте QR. Можно вставить одну ссылку вместе с подписью из сообщения бота. Нажмите «Импортировать». Для HTTP показывается предупреждение о передаче ключей без шифрования; используйте HTTPS, если он доступен.
4. Для первой проверки выберите знакомый рабочий Xray-сервер во вкладке «Серверы», вернитесь на главную и нажмите большую круглую кнопку. Подтвердите системный запрос Android на VPN.
5. Дождитесь «Маршрут проверен» и IP выхода. Откройте сайт в браузере. Затем проверьте режим «Авто» и отдельно OpenFlux/Cups.
6. olcRTC включается в настройках как экспериментальный транспорт. Для него нужен совместимый сервер; UDP блокируется этой сборкой.

При ошибке Rayren удерживает VPN и блокирует защищаемый трафик. Чтобы вернуться к обычному интернету, нажмите большую круглую кнопку. После изменения DNS, списка приложений или правил сохраните настройки и подключитесь заново.

Для отчёта об ошибке: «Журнал → Экспортировать отчёт». Приложите отчёт, модель телефона, версию Android, тип сети и укажите, какой транспорт проверяли. Ключи и ссылки подписок в отчёт не входят.

17.10.2026 все три предоставленные ссылки — основная HTTP, основная HTTPS и INCY — успешно проверены в режиме совместимого JSON: каждая импортировала 9 уникальных профилей (8 VLESS + 1 Hysteria). Этот режим теперь запрашивает приложение. Старый формат основной выдачи во время диагностики периодически отвечал HTTP 500; URL подписок и серверные настройки не менялись. В 0.1.3 импортируются серверы и состав JSON-балансировщиков; политика Smart Balance (leastPing) задаётся Rayren. После обновления APK нажмите обновление подписок. Внешние правила маршрутизации из JSON не исполняются.

## Что включено

- VLESS/REALITY, Trojan, Shadowsocks, Hysteria2 и VMess через Xray.
- Встроенные OpenFlux/Cups и другие поддерживаемые провайдеры; olcRTC Telemost/Jitsi/WB Stream.
- «Авто», «По пингу», ручной выбор, пояснения по нажатию на значок информации и переключение сервера при активном VPN.
- Группы подписок с именами и своим пингом; Smart Balance из JSON — отдельный маршрут.
- HTTPS-пинг одного сервера или списка; активный маршрут, скорость и кнопка пинга в уведомлении.
- Единый раздел обхода: автоматические группы сайтов/приложений, .ru/.рф, свои домены и ручной выбор приложений.
- DNS interception, DoH, DoT, обычный DNS, direct/system DNS и отдельные DNS-правила для доменов.
- DIRECT/PROXY/BLOCK, домены/CIDR/GeoIP/GeoSite/порты/протоколы, LAN, per-app VPN, контроль IPv6.
- Шифрованное Android Keystore хранилище, подписанный manifest Ed25519 с заранее доверенным ключом, условное обновление подписок, QR, clipboard, share и deep link.

Это alpha: готовность функций и границы проверки перечислены в [docs/REQUIREMENTS_STATUS.md](docs/REQUIREMENTS_STATUS.md). Ежедневная/месячная статистика, IPv6-only, серверная нагрузка, управление provider CAPTCHA и production release пока не заявляются.

## Сборка

JDK 21, Android SDK 36, build-tools 35/36, NDK 28.2.13676358, Go с поддержкой toolchain 1.27, Git, Python 3. Gradle wrapper: 8.14.3. В Windows используйте ASCII-путь; скрипт создаёт junction в TEMP, сохраняя исходники на месте.

```powershell
# Быстрая пересборка приложения из комплекта с готовыми native-библиотеками:
./scripts/build-apk.ps1 -Sdk C:/Android/Sdk -JavaHome 'C:/Program Files/Java/jdk-21'

# Полная пересборка native из вложенных исходников:
./scripts/build-native.ps1 -Sdk C:/Android/Sdk -GoExe C:/Go/bin/go.exe
./scripts/build-hev.ps1 -Sdk C:/Android/Sdk
./scripts/build-apk.ps1 -Sdk C:/Android/Sdk

# JVM + native integration:
./gradlew.bat :domain:test
./scripts/test-native.ps1 -GoExe C:/Go/bin/go.exe
```

`native/upstreams` в репозитории и архиве содержит точные исходники четырёх встроенных проектов. `native/vendor` содержит исходники Go-зависимостей; `native/go.mod`, `native/go.sum`, `vendor/modules.txt` фиксируют версии. Скрипт native-сборки использует исходники upstream и проверенные Go module checksums; он может загружать toolchain и build tools. Для повторного получения upstream-исходников предусмотрен `scripts/fetch-upstreams.ps1` с закреплённым SHA Veil и его submodules.

Подписанный debug APK не предназначен для публикации в магазине. Production-ключ подписи не создавался. Ключ подписи не входит в репозиторий; самостоятельная сборка будет подписана вашим локальным ключом.
