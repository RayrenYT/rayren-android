# Rayren 0.1.5-alpha — 21.10.2026

Тестовая сборка Android 8+, arm64-v8a, versionCode 6. Устанавливается поверх 0.1.4 с прежней подписью. Исходники и лицензии поставляются рядом с APK.

## Изменения по восьми замечаниям

1. При активном VPN разрешено удалять другие профили. Текущий подключаемый/подключённый профиль защищён от удаления. Удаление очищает его принадлежность подпискам; обновление исходной подписки может вернуть профиль.
2. Отключение отменяет нативные HTTP-проверки и ожидание запуска OpenFlux; поздний результат запуска очищается. DNS-разрешение ограничено четырьмя секундами и отменяется на Android 10+. На Android 8–9 применяется ограниченный пул фоновых задач. При явном отключении TUN освобождается до завершения очистки движков. Это не измерение времени реакции на телефоне: внутренний запрос стороннего провайдера может ещё завершаться в фоне, повторный запуск сериализован.
3. В едином разделе обхода добавлен отдельный переключатель «Сайты из БС напрямую»: конкретные сервисы и их домены/CDN, включая .com/.net. Это стартовый каталог, а не официальный универсальный список оператора. Для перечисленных доменов DNS также направляется напрямую через DNS физической сети; остальные DNS-запросы сохраняют выбранный режим. Обычный обход всех .ru/.рф включается отдельно. Переключатель не делает недоступный у оператора сайт доступным.
4. «Авто» перемешивает кандидатов внутри групп доступности. Начальный выбор случайный; проверенный работающий маршрут сохраняется, а после неудачи раньше пробуется ещё не проверенный тип транспорта. Постоянного случайного переключения работающего VPN нет.
5. RU-2/РУ-2/Россия 2 исключаются из «Авто» и «По пингу» по названию профиля/адреса. Балансировщик с таким распознанным участником тоже исключается из автоматического выбора. Ручной выбор сохранён. Полностью переименованный узел без соответствующего признака невозможно надёжно опознать по названию.
6. Начата интеграция Telegram: отдельный локальный модуль одноразовой привязки, проверка владельца, выдача и отзыв ключа устройства, получение основной подписки и Cups по актуальным правам. Девять тестов проходят. Модуль ещё не подключён к APK и серверу; кнопки входа через Telegram в этой версии нет. План подключения — integration/telegram/README.md.
7. Серверы остаются в группах подписок, добавлены страницы по 50 элементов и поиск. Проверен импорт 500 различных серверов, десять страниц без потерь, размер сохранения в пределах лимита. Производительность прокрутки на телефоне пока не измерена.
8. В настройки добавлены сортировка серверов по пингу, пинг при открытии, обновление при открытии и включение/выключение фонового обновления. Сортировка действует внутри подписки, неуспешные проверки идут в конце. Автопинг работает только для текущей страницы раскрытой группы, свежие результаты до пяти минут повторно не проверяются. Обновление при открытии ограничено одним запуском за пять минут. По умолчанию массовый автопинг выключен; прежнее фоновое обновление сохранено. Настройки списка можно сохранить при активном VPN.

## Проверки

- 128 JVM-тестов: 116 domain + 12 app, без ошибок и пропусков.
- Нативные проверки: 20 сгенерированных конфигураций; настоящий VLESS/SOCKS/DNS/HTTPS; блокировка трафика при недоступном прокси; scoped DNS и прямой HTTP для каталога БС; DoT с проверкой сертификата; ошибочные пароль/сертификат; GET/тайминги/редиректы; отмена зависшего HTTP и позднего запуска провайдера.
- Девять Python-тестов привязки: одноразовость, срок действия, отсутствие доступа по одному коду, конкурентный обмен, проверка владельца и актуальных прав, отзыв, отсутствие открытых токенов в базе.
- Сборка APK и Android lint. Состав APK, совпадение встроенного native с AAR, выравнивание ELF 16 КиБ проверяются scripts/package-release.py.
- Локальные TLS-фикстуры ограничены TLS 1.2 и запрашивают клиентский сертификат для совместимости со средой проверки. Проверка доверия и имени сохранена; недоверенные сертификаты отвергаются. Производственные TLS-настройки не ослаблялись.

## Ограничения

Реальное устройство не участвовало в проверке. Быстрота отключения на Vivo/Samsung, внешний вид, поведение БС конкретного оператора, Wi-Fi → мобильная сеть, LiveBridge и расход батареи требуют проверки по DEVICE_TEST_CHECKLIST.md. Все восемь пунктов не объявляются полностью завершёнными: Telegram находится на первом этапе, не в рабочей интеграции.

Воспроизведение: Gradle `:domain:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`; `scripts/test-native.ps1`; `python -m unittest discover -s integration/telegram -v`; `python scripts/package-release.py`. Хеши готовых файлов — artifacts/SHA256SUMS.txt.
