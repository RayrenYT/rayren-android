# Rayren 0.1.8-alpha — 23.10.2026

Android 8+, ARM64, versionCode 9. Установка поверх прежнего Rayren с сохранением данных; подпись не меняется. RU-2 по-прежнему разрешён в подборе.

## Подписки и подбор

1. Кнопка корзины в карточке подписки и пункт «Удалить подписку» в меню. Требуется подтверждение. Удаляются ссылка и исключительно её профили; общие с другой подпиской и отдельные ручные профили сохраняются. Если удалён активный маршрут, существующий сервис делает RESELECT на том же TUN. При отсутствии замены трафик удерживается до явного отключения VPN.
2. Импорт до 5000 профилей и 16 МиБ данных; зашифрованное хранилище до 64 МиБ. Лимиты действуют на вход, HTTP-поток, JSON/URI/Base64, подписанный manifest и личный bundle. Страницы по 50 и поиск сохранены. Большая JSON-группа с балансировщиком свыше 32 узлов импортирует отдельные серверы с предупреждением, не создавая тяжёлый observatory на тысячи участников.
3. «Подбор» в каждой группе: отдельные переключатели AUTO/SMART. Ручная группа тоже управляется отдельно. Общий профиль участвует, если включён хотя бы один источник-владелец. Отключение всех источников не разрешает скрытый fallback; ручной выбор остаётся доступен. Настройки сохраняются при обновлении/смене ссылки и повторном импорте аккаунта. Старые записи включены по умолчанию.
4. Тип подписки: «Определять автоматически», «БС / резерв», «Обычные серверы». Определение учитывает OpenFlux/Cups/olcRTC и явные пометки в названиях. Пользователь может исправить распознавание без переименования. Для общих профилей явная резервная пометка имеет приоритет. AUTO использует БС после отказа подходящих обычных маршрутов; на новой физической сети история начинается заново. SMART сохраняет сравнение проверенных маршрутов по задержке и ошибкам.

Это распознавание назначения маршрута, не универсальный детектор белых списков оператора. HTTPS-проверка через выбранный транспорт подтверждает доступ к проверяемой цели; она не гарантирует работу всех сайтов и приложений.

## Первый шаг из Smart 2

Фильтры «Работают / Не проверены / Не отвечают» внутри подписки. Свежесть результата — пять минут, смена физической сети очищает измерения. Тап по текущему маршруту и кнопка «Почему выбран этот сервер?» открывают реальные причины, HTTPS-оценку и число альтернатив с ошибками в текущей сети. Отсутствие данных показывается явно. Реальные пользовательские потоки пока не классифицируются, их успех не выдумывается.

SubscriptionMetadata и Quick Settings Tile — следующая часть UX-этапа; persistent network memory, circuit breaker, multi-target diagnosis, RouteReceipt и updater ещё не реализованы. Полное Smart 2.0 не заявляется. Подробности — SMART_2_ROADMAP.md.

## Автоимпорт Telegram

Включены /rayren, старт rayren_app и кнопка в «Моя подписка» существующего бота. Пилот выдаёт одну личную группу: основную подписку и Cups только при доступе. Актуальные права прочитаны для 15 привязок, у 4 есть Cups. Живой HTTPS-тест двух аккаунтов подтвердил 9 основных документов у каждого и один резервный профиль только у владельца Cups. Личные идентификаторы и ключи в отчёты не выводятся. Временные тестовые ссылки удалены; неизвестный/удалённый ключ даёт 403.

В ходе проверки обнаружена пропущенная завершающая обработка старой выдачи; исправлено применение существующей цепочки response hooks до упаковки личного ответа. Постоянные маршруты и текущий SNI совпадают с INCY. shortId меняется между обычными запросами самой действующей выдачи — этот факт проверен отдельно. Клиентские базы/маршруты/оплаты/комнаты не менялись. Рассылки клиентам не было.

## Проверки

- 157 JVM-тестов: 143 domain + 14 app; ошибок и пропусков нет. Включены 5000 URI/Base64, 1200 JSON-профилей, HTTP chunked больше прежних 2 МиБ, отказ свыше 16 МиБ, границы количества, удаление общих/последних групп, выбор источников, тип БС, миграция, объяснение без секретов, устаревание/восстановление статуса.
- 25 Python-тестов модуля Telegram/личной выдачи; отдельно fake-update проверки адаптера в серверном venv без сообщений в Telegram.
- Нативные generated configs, VLESS/SOCKS/DNS/HTTPS, fail-closed, DIRECT/BLOCK, Smart Balance, DoT, отвергание чужого сертификата/пароля, отмена HTTP и позднего запуска — проходят. AAR/рабочий native код не менялись относительно 0.1.7.
- Локальная среда снова не принимала сертификат HTTPS-фикстуры при TLS к голому IP. Фикстуры используют явное проверяемое DNS-имя/SNI и loopback resolution. Доверяется только тестовому сертификату; отрицательные TLS-тесты сохранены. Настройки TLS приложения и защита ОС не изменялись.
- APK собран, lint без ошибок. Проверки подписи, ELF/ZIP 16 КиБ и состава APK фиксируются при упаковке в artifacts.

ADB не обнаружил устройств. UI, переход Telegram → браузер → Rayren, удаление активной группы/смена сети с живым трафиком, расход батареи и скорость прокрутки 5000 записей требуют телефонной проверки. Измеренные тестовые времена на ПК не являются оценкой производительности телефона.
