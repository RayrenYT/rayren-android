# Rayren 0.1.4-alpha · 19.10.2026

Package com.rayren.android; versionCode 5; Android 8+, target 36; arm64-v8a. APK для обновления поверх прежней версии без удаления данных. Серверная инфраструктура не изменялась.

## Изменения

- Под каждой подпиской видна кнопка «Обновить», в том числе у свёрнутой группы. Вверху — «Обновить все».
- Меню ⋮: закрепление/открепление и редактирование имени и URL. Ссылка скрыта до нажатия глаза; доступны копирование и вставка. Новая ссылка проверяется загрузкой до замены данных. Ошибка сохраняет прежнюю подписку; дубликат другой подписки отклоняется. Закрепление хранится в зашифрованном хранилище; старые записи читаются как незакреплённые.
- Смена физической сети сбрасывает прежние измерения. У каждого поколения сети собственная история ошибок; результат начатого ранее запроса не засчитывается новой сети. Отправка новых соединений привязана к выбранной физической сети через Android ConnectivityManager. TUN остаётся открытым при переключении маршрута.
- «Авто» после первого неработающего Xray даёт попытку ещё не проверенному OpenFlux/Cups, прежде чем идти по остальным Xray. Работающий маршрут выше непроверенного. «По пингу» включает разные движки в начальный список до 12 кандидатов. При смене сети список проверяется заново. Cups выбирается после успешной проверки HTTPS, а не только по названию профиля.
- В обоих автоматических режимах восстановление включено независимо от настройки ручного переподключения. Ручной режим сохраняет выбранный профиль. Два провала проверки активного маршрута приводят к восстановлению; повтор после первого провала планируется через 3 секунды, плюс время самого запроса.
- Фоновые опросы, повторные уведомления и таймер интерфейса оптимизированы; отдельный отчёт — BATTERY_AUDIT_0.1.4.md.

## Проверки

Чистая сборка :app:clean :domain:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug выполнена успешно. 117 JVM-тестов: 105 domain и 12 app, без ошибок и пропусков. Новые проверки охватывают закрепление, совместимость старого хранилища, замену URL, сохранение общих/ручных профилей, резерв Cups после блокировки Xray, изоляцию поколений сети, разнообразие начальной проверки, отмену устаревшего замера и подавление одинаковых уведомлений.

scripts/test-native.ps1 пройден: 19 сгенерированных конфигураций; реальный локальный VLESS→HTTPS, DNS interception, удержание трафика после остановки core, DIRECT/BLOCK при нерабочем прокси, Smart Balance с нерабочим первым узлом, домен через удалённый прокси, доверенный DoT и отклонение неверного сертификата/пароля, полный HTTPS GET с задержкой ответа и запрет небезопасного URL/redirect/недоверенного TLS.

Android lint: 0 ошибок, 2 предупреждения — DiscouragedApi и ChromeOsAbiSupport. Подпись APK v2 проверена; SHA-256 сертификата 8d4945113b6a4f4c971103b4b723a985001ce1a89e2e90e3694dbbaf56420c31 совпадает с предыдущей версией. ZIP alignment 16 KiB проверен.

Нативные исходники и AAR в этой версии не менялись. Используется тот же собранный движок, что в 0.1.3. package-release.py проверяет совпадение libgojni.so в APK и AAR, ARM64, ELF alignment 16 KiB, geo assets, лицензии и нулевые ошибки lint. Итоговые размеры и SHA-256 — artifacts/SHA256SUMS.txt; результаты упаковки — artifacts/verification.txt.

## Границы

ADB не обнаружил устройств. Реальная смена Wi-Fi→мобильная сеть с белыми списками, работа Cups, Compose-интерфейс и LiveBridge на Vivo/Samsung требуют телефонной проверки по DEVICE_TEST_CHECKLIST.md. Энергопотребление в процентах/мА·ч не измерено; меньше итераций контроллера не означает такой же процент экономии батареи.

Активный нативный запрос завершается или достигает таймаута перед обработкой следующего маршрута; его результат проверяется на актуальность. «По пингу» использует ограниченный начальный список, а не обещает глобальный минимум среди всех серверов. Smart Balance продолжает собственные проверки узлов внутри Xray. Проверки работоспособности и сетевые keepalive сохранены.

## Воспроизведение

JDK 21, Android SDK 36, Gradle 8.14.3; для Windows — ASCII junction на проект. Команда Gradle приведена выше. Нативные интеграционные проверки — scripts/test-native.ps1. Упаковка — python scripts/package-release.py. GPLv3 и соответствующие исходники всех встроенных движков включены в архив рядом с APK.
