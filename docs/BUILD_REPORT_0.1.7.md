# Rayren 0.1.7-alpha — 23.10.2026

Тестовая сборка Android 8+, arm64-v8a, versionCode 8. Подпись прежняя, установка поверх 0.1.6.

## RU-2

Убрано временное исключение RU-2/РУ-2 и содержащих его балансировщиков из AUTO и SMART. Убраны предупреждение в карточках и старое пояснение. Правило «обычные серверы сначала, БС как резерв» сохранено. Возврат узла выполнен по сообщению владельца о ремонте; отдельная проверка Telegram/WhatsApp через RU-2 в этой сборке не проводилась.

## Тестовый автоимпорт из бота

Сценарий: «Серверы → Моя подписка из Telegram» → существующий @rayrenhelpbot → личная кнопка → «Открыть Rayren» → подтверждение импорта. В боте предусмотрена команда `/rayren`, старт `rayren_app` и ссылка в «Моя подписка». Рассылка клиентам не выполняется. Сайт открытия указывает на APK 0.1.7 и соответствующие исходники.

Вместо ручного копирования двух ссылок импортируется одна обновляемая группа «Мой Rayren»: основная подписка со Smart Balance плюс Cups при наличии доступа. Выдача связывается с доверенным Telegram ID существующего бота. Основная привязка, включение клиента, оплаченный срок, тариф, назначение Cups и включение комнаты читаются при каждом обновлении. Старые клиенты без записи о сроке сохраняют установленную ранее политику доступа.

Персональная ссылка содержит случайный секрет, сервер хранит его SHA-256. Срок 90 дней; новую ссылку можно получить той же кнопкой. Стабильный случайный account_id позволяет заменить ссылку без второй группы и сохранить имя/закрепление. На аккаунт допускается до 20 актуальных ссылок; при выдаче следующей наиболее старая удаляется. Ручные подписки не переводятся в управление аккаунта автоматически.

Данные основного аккаунта и Cups разбираются и сохраняются вместе. Ошибка источника даёт 503 и сохраняет старое содержимое. Успешный ответ о потере доступа удаляет из группы отозванные профили при обновлении; чужие подписки и их совместно используемые профили сохраняются. Установленный VPN переключает удалённый активный профиль через существующий механизм. Это обновление подписки, не мгновенное отключение уже выданного сетевого ключа: отзыв самого доступа обеспечивается действующей серверной системой.

## Границы пилота

- Ссылка даёт доступ к подписке, её нельзя пересылать. Это авторизация личной кнопкой бота и секретной ссылкой, а не ранее подготовленная схема одноразовой привязки устройства с verifier.
- Одноразовый модуль account_pairing.py сохранён для следующего этапа, но в пилоте не используется. Нет отдельного экрана входа/выхода из аккаунта или списка устройств.
- Собственная база ссылок rayren-app-access.db отделена от существующих баз клиентов/оплат. Чтение клиентских таблиц идёт через SQLite mode=ro. Модуль не назначает комнаты и не создаёт оплаченный доступ.
- Персональный URL не передаётся веб-серверу в ссылке открытия: используется fragment, затем он удаляется из адресной строки. На странице нет сторонних скриптов. Доступ к самой подписке идёт по HTTPS, без кэша; для нового маршрута предусмотрено исключение URL из access-логов и ограничение частоты.
- Для HTTP-обновления права подтверждаются на момент запроса. Фоновое обновление использует текущие настройки приложения; оно не является непрерывной синхронизацией.

## Проверки

143 JVM-теста без ошибок и пропусков; 24 локальных Python-теста, включая разделение двух пользователей, отсутствие Cups без доступа, просроченный/отозванный ключ, обновление прав, запрет подмены владельца и атомарную обработку ошибок. 15 тестов нового модуля прошли в изолированной папке RU1 с временными базами в /dev/shm.

Чтение реальных привязок на RU1: 15 основных подписок, 4 с доступным Cups, ошибок 0. Не публикуются Telegram ID, URL, UUID и ключи. Этот подсчёт не равен ручной проверке каждой кнопки у всех клиентов.

Нативные тесты VLESS/SOCKS/DNS/HTTPS/DoT, обхода БС и отмены запросов прошли. Android lint без ошибок. Нативный AAR не менялся. Подпись и выравнивание 16 КиБ проверяются при упаковке. Реальный переход Telegram → браузер → Android и работа VPN на телефоне требуют проверки пользователем.

Серверная установка и проверки живой выдачи фиксируются отдельно в рабочей папке ops/android-autoimport-20261023. APK не содержит серверных токенов/клиентских баз, а только адрес публичного бота и проверку собственного HTTPS-маршрута.
