# Rayren 0.1.2-alpha · проверка сборки 18.10.2026

Тестовый APK для установки поверх предыдущих версий. versionCode 3; package com.rayren.android; arm64-v8a; Android 8+. Native-библиотеки не изменены. Соответствующие исходники и лицензии включены в source.zip.

## Реализовано

Пункты пользователя 1, 2, 3, 6, 11 с (!) и пункт 12: пояснения режимов, отдельные группы обхода сайтов/установленных приложений, пользовательские домены, HTTPS-пинг в списке серверов, активный сервер и пинг в уведомлении, смена сервера/режима при сохранении TUN, одна круглая кнопка подключения. Подробности и оставшаяся очередь — USER_PRIORITIES.md.

Пинг других серверов не перезапускает активный core. OpenFlux/olcRTC не запускают параллельный сеанс занятого движка: другой профиль отмечается «Движок занят подключением». Для проверки такого профиля нужно освободить движок; активный профиль проверяется через существующий туннель. Очередь можно остановить после текущей проверки. Выбор сервера останавливает очередь и ждёт завершения текущей отдельной проверки, затем меняет маршрут.

## Результаты и границы

- Kotlin/Compose и APK собираются; Android lint без ошибок.
- Domain: 79 тестов проходят, включая миграцию настроек старого хранилища, исключения приложений, приоритеты маршрутизации, режимы и нормализацию доменов.
- App: 12 из 12 тестов проходят. Итого 91 из 91 JVM-тестов без ошибок и пропусков, включая положительные HTTPS-проверки импорта и взаимное исключение сеансов транспортов.
- В ранних прогонах локальные HTTPS-тесты не проходили. Диагностический TrustManager показал issuer `CN=Avast Web/Mail Shield Self-signed Root, O=Avast Web/Mail Shield, OU=generated by Avast Antivirus for self-signed certificates` вместо сертификата MockWebServer. Проверка доверия при диагностике оставалась включённой. Диагностический код удалён; исходные проверки строгого TLS сохранены и в итоговом прогоне прошли. Перенос теста на ::1 дал системный отказ соединения и был отменён. Настройки антивируса агентом не менялись; причина прекращения перехвата не устанавливалась.
- Все 18 генерируемых конфигураций принимаются реальным Xray. Новый native-тест подтверждает: свой домен выходит DIRECT при заведомо неработающем прокси; явный BLOCK для домена группы и обычный PROXY не превращаются в обход.
- Итоговый native-прогон проходит полностью: VLESS→HTTPS, перехват DNS, отказ после остановки транспорта; проверка DIRECT/BLOCK; положительный DoT через SOCKS, отклонение недоверенного сертификата/неправильного пароля, жизненный цикл. Предыдущие TLS-сбои (x509 unknown authority / EOF) на итоговом прогоне не воспроизвелись.
- Текущий ADB-список пуст. Установка, внешний трафик, шторка, смена сервера, жизненный цикл отдельного probe-процесса и поведение интерфейса на физическом Android не проверены. Для этого подготовлен DEVICE_TEST_CHECKLIST.md.

TLS-проверку приложения не отключали, доверие к сертификату Avast в тестовые клиенты не добавляли. package-release.py требует нулевых ошибок и пропусков JVM-тестов и нулевых ошибок Android lint; исключения для этой сборки не используются.

## Повторная проверка

Сборка через scripts/build-apk.ps1 (JDK 21, Android SDK 36). Локальные тестовые сертификаты не должны подменяться средствами инспекции HTTPS. Команды: :domain:test, :app:testDebugUnitTest, :app:lintDebug, scripts/test-native.ps1. Подпись APK и 16 KiB alignment проверяются средствами Android build-tools.
